## 二、玩法规则

### 1. 对局制
- 一局 **5 分钟**，到点自动开启下一局。
- 得分榜**跨局累计**；观众离场后，后续观众按分数补位排名。
- 对局内显示剩余时间、当前总分、命中率。

### 2. 地鼠类型与计分
| 地鼠/事件 | 得分 | 说明 |
|---|---|---|
| 普通地鼠 | **+10** | 常规露头，击中后缩回。 |
| 金鼠（金色） | **+30** | 露头时间更短，奖励分更高，伴随金色礼花。 |
| 炸弹（黑色） | **−15** | 踩中扣分并清空本人连击，全屏红闪提示。 |
| 送礼事件 | **+20** | 按本人连击倍率结算，叠加礼物卡片与爆发粒子。 |

### 3. 连击倍率
- 同一观众每 **3 次连击**提升一档倍率，倍率 **×1 → ×2 封顶**。
- 踩到炸弹或打空（指令未命中）后，本人连击清零、倍率回到 ×1。

### 4. 难度递增
- 随对局进度，地鼠露头间隔和停留时间逐步缩短。
- 后半场概率一次冒出两只地鼠，提升紧张感。

## 三、观众互动方式（弹幕指令）

观众在评论区发送以下指令即可参与击打：

| 指令 | 作用 |
|---|---|
| `#打1` ~ `#打9` | 砸对应编号洞口的地鼠（1–9 对应 3×3 九宫格）。 |
| `#左` / `#中` / `#右` | 砸对应一列当前露头的地鼠。 |
| `1` / `2` / `3` | 同左/中/右，按列击打。 |
| `#金鼠` / `#黄金` / `#金` | 优先砸当前露头的金鼠。 |
| `#普通` / `#地鼠` | 优先砸当前露头的普通地鼠。 |

除指令外，以下直播间行为自动触发氛围反馈：
- **进场**：观众头像上头像墙，飘入场提示与爱心粒子。
- **关注**：飘关注提示与爱心粒子。
- **点赞**：飘点赞提示与轻量爱心粒子。
- **评论/弹幕**：评论以气泡形式在画面左侧滚动展示。
- **送礼**：弹出礼物卡片（礼物名 + 数量 + 送礼人），触发礼花、环形冲击波和加分。

## 四、直播间视觉效果

- **场景**：3×3 草地卡通横版场景，地鼠从洞口露头/缩回动画。
- **击中反馈**：对应颜色粒子散开 + 环形冲击波 + 飘分弹跳放大；金鼠为金色系，普通鼠为绿色系，炸弹为红色系。
- **礼物特效**：金色渐变礼物卡片入场弹入、上下浮动、周期性扫光高光、角落星芒；双色礼花 + 两圈环形冲击波。
- **榜单**：右侧玻璃质感得分榜，前三名配金/银/铜 3D 动态皇冠、呼吸光环；榜一带旋转流光与环绕金粒；第四名及以后按分数排列。
- **头像墙**：进场观众头像/昵称首字横向排列，最多展示固定数量，超出依次补位。
- **音效与背景音乐**：击中、金鼠、踩雷、礼物、打空、进场、关注、点赞、弹幕各有对应短促音效；循环播放俏皮轻快背景音乐，可全局静音。

## 五、需要的直播数据（官方开放能力）

| 数据项 | 用途 |
|---|---|
| 直播间基础信息 | 直播间 ID、直播时长，用于绑定对局。 |
| 评论/弹幕数据 | 解析击打指令与普通评论气泡。 |
| 点赞行为与点赞总数 | 触发点赞反馈、点赞类挑战。 |
| 关注事件 | 触发关注反馈、计入活跃互动。 |
| 礼物事件 | 礼物名称、数量、送礼人，触发礼物特效与加分。 |
| 用户信息 | 用户 ID（哈希脱敏）、昵称（首字脱敏）、头像，用于榜单与头像墙。 |

> 合规说明：仅通过平台官方 OpenAPI / 官方长链接获取已授权数据；昵称做脱敏展示，不保存评论原文与原始个人信息；数据保留期限按平台与合规要求设置。

## 六、UI 设计（提审需补正式 UI 稿）

画幅 1920×1080 透明叠加层，挂在直播画面之上；本地演示已有可运行画面，提审前需按《互动工具设计建议》补齐正式 UI 稿。

### 1. 看播端 UI（观众看到的游戏叠加层）

| 区域 | 位置 | 内容 |
|---|---|---|
| 对局 HUD | 顶部居中 | 剩余时间、当前总分、命中率、当前连击倍率。 |
| 游戏主场景 | 画面中央 | 3×3 草地洞口网格，地鼠露头/缩回动画，击中粒子、冲击波、飘分在场景内播放。 |
| 玩法说明面板 | 左上 | 指令列表：`#打1~9`、`#左/#中/#右`、`#金鼠`、`#普通`、炸弹提示、送礼加分。 |
| 得分榜 | 右上 | 前五名：头像/脱敏昵称/分数；前三名金/银/铜 3D 皇冠 + 呼吸光环，榜一带旋转流光与环绕金粒。 |
| 头像墙 | 左下 | 进场观众头像/昵称首字横向排列，超出依次补位。 |
| 弹幕气泡 | 左侧纵向 | 普通评论与进场/关注/点赞提示气泡依次上浮滚动。 |
| 礼物卡片 | 右下纵向堆叠 | 送礼人、礼物名、数量；入场弹入、浮动、扫光高光与星芒。 |

### 2. 主播端 UI（管理台）

| 区域 | 内容 |
|---|---|
| 数据面板 | 实时榜单、命中率、在场观众数、已发互动条数。 |
| 气氛控制 | 情绪/气氛档位 L0–L4 手动切换；静音特效开关；仅预设角色开关。 |
| 参数设置 | 对局时长、粒子上限、特效强度（按平台规范开放必要项）。 |
| 调试区（开发期） | 模拟回放、单步事件注入、帧率/粒子数监控；正式上线不向主播暴露。 |

### 3. 素材 UI（图形资产）

- 地鼠三形态：普通鼠（棕色）、金鼠（金色冠饰）、炸弹鼠（黑色炸弹造型）。
- 背景：暖色调草地小丘横版场景。
- 榜单装饰：金/银/铜皇冠、呼吸光环、榜一流光与金粒、奖牌。
- 特效素材：礼物盒图标、礼花粒子、环形冲击波、爱心粒子、飘分字体。
- 图标：玩法说明、点赞、关注、送礼等小图标。
