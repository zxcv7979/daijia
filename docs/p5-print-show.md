# 虚拟打印表演

这一层只在画面里模拟一台打印机。没有切片、没有 STL 导出、没有封闭性或壁厚检查，也不会连接真实打印机。

## 从管理页开打

1. 打开 `/admin/`。
2. 在「虚拟打印」里选风格：卡通、写实或全息。
3. 时长用 30–60 秒，默认 45 秒，点「创建任务」。
4. 特效页 ` /overlay/?preview=1&hud=1 ` 会看到热床、喷头、料丝和进度灯。有 P4 角色时用那颗头，否则用场景里的参数化头。

进度条拖动是调试台的「时间轴」。它会把 GSAP 时间轴和打印进度一起拖到对应百分比，用来预览任意阶段。点「回到直播」恢复直播进度。

「失败并补偿」把热床上的任务标成失败，并立刻排入一条同样风格的补偿重打，然后再继续后面的队列。

层纹、环绕、揭晓灯三个滑杆写入 `POST /api/print-show/settings`。同一组参数也在 `config/default.yaml` 的 `print_show`：

- `default_duration_sec`：默认 45。管理页限制在 `show_min_sec` 30 到 `show_max_sec` 60。
- `grain`、`camera_orbit`、`reveal_lights`：层纹、环绕和揭晓灯光。
- `queue_jump` / `jump_min_style`：插队开关和门槛。
- `overlay.sfx` 里 `print_progress_90`、`print_progress_100` 留空就是静音。文件放到 `apps/overlay/public/sfx/` 后写成 `/overlay/sfx/文件名`。

## 阶段

| 进度 | 阶段 | 画面 |
| --- | --- | --- |
| 0–5% | 预热 | 灯亮、喷头归位，HUD「任务已接收」 |
| 5–85% | 层生长 | 只改裁切平面和封口片，层纹、扫描线 |
| 85–95% | 精修 | 扫描线，短暂线框再回到实体，支撑让开 |
| 95–100% | 揭晓 | 底座灯、光爆发、镜头环绕 |
| 90% | 屏息 | 情绪节拍 `hold_breath` |
| 100% | 爆发 | 情绪节拍 `burst` |

每一帧只改 uniform 和裁切平面的常数。网格在进场时创建一次。不封闭的模型用封口片挡住空心内壁。

## 礼物档和队列

- L3 卡通用默认时长，排在队尾。
- L4 全息用 `show_max_sec`（默认 60 秒）。
- 只有达到 `jump_min_style`（默认全息）的任务可以插到正在打印的那一件后面。
- 插队不会打断热床上已经开始的任务。
- `queue_jump: false` 时全部按到达顺序。
- 补偿重打不享受插队，它只是变成下一件。

## 无头检查和实机

```bash
python scripts/print_queue_bench.py --jobs 20
python scripts/soak_hook.py --jobs 20
```

`soak_hook.py` 只是留给 P6 的入口，现在会跑上面这条短队列，不会做长时间浸泡。

本环境没有 OBS 和独立 GPU。1080p 实机 60fps，以及连续 20 条在浏览器里的泄漏、穿模、黑屏、卡死，标记为 **待实机验收**。无头脚本确认 20 条都能到 `done`，并且进度消息里 `rebuild_geometry` 始终是 false。

实机时：OBS 浏览器源指向特效页，连续创建 20 条 30 秒任务，看 HUD 帧率、任务切换有没有黑屏，以及内存曲线是否一直上涨。
