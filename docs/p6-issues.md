# P6 已知问题

- 8 小时 OBS / GPU 浸泡没有在这台机器上跑。短跑只覆盖进程内事件、打印队列和指标。画面泄漏、黑屏和显存要实机看。
- 官方适配器仍是桩。它的降级状态是预期，浸泡不会为此告警，也不会连接平台。
- 断线罐头动画在特效页本地推进进度和 GSAP 时间轴。它不补真实事件；事件补发仍靠 30 秒 WebSocket 缓冲。
- 照片生成失败或质检失败时回到预设「圆圆」。这里没有 GPU 重建，失败路径就是这条回退。
- 保留期清理只删到期的加密照片行，不删预设 GLB。预演默认不删除。
- 浸泡脚本把每次打印和回退写进临时库，不写仓库里的 `data/live_show.db`。
- 负载降档看的是调用方传入的 CPU/GPU 利用率，或管理接口的 `load_level`。本机没有持续采样 GPU 的守护进程。
- P6 不再往下加功能。真实打印机、切片和平台采集都不在范围内。
