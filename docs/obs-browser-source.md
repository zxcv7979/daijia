# 把特效页放进 OBS

特效页是 1920×1080 的透明浏览器源，吃的是本机模拟回放，不连接直播平台。

## 先把服务跑起来

```bash
bash scripts/start.sh
```

Windows 用 `scripts\start.bat`。浏览器里先打开 http://127.0.0.1:8787/overlay/?preview=1&hud=1 看有没有画面。`preview=1` 会铺一层深色底，方便在普通浏览器里看。OBS 不要加这个参数。

## OBS 设置

1. 来源点「+」，选「浏览器」。
2. 名称随便，比如「直播特效」。
3. URL 填 `http://127.0.0.1:8787/overlay/`
4. 宽度 `1920`，高度 `1080`。
5. 帧率 `60`。勾选「控制音频」如果以后放了音效；默认没有声音。
6. 自定义 CSS 留空。不要加不透明背景。
7. 取消「当源不可见时关闭浏览器」。演出中隐藏再打开会重新连 WebSocket。
8. 确定后，这条源应该是透明的，只看见头像、弹幕和礼物。底下可以放摄像头或别的来源。

OBS 的「设置 → 视频」里，基础画布也用 1920×1080，输出帧率 60。

## 改配置不用重新构建

`config/default.yaml` 的 `overlay` 段和 `config/mappings.yaml` 的粒子数、关键词，特效页大约每秒重新读一次。

- `mute: true` 或管理页「静音」关掉音效。
- `sfx` 里某项写成 `/overlay/sfx/礼物.mp3` 之前，把文件放到 `apps/overlay/public/sfx/礼物.mp3`，然后重新 `npm run build`（静态文件要进 dist）。路径留空就是不播放，不会自己出声。
- `max_fx` 最大 8，`max_particles` 最大 20000。帧时间连续超过 `frame_budget_ms`（默认 12）就会降档：粒子减半，并跳过标记为 `secondary` 的次要特效。

## 调试台

管理页 http://127.0.0.1:8787/admin/ 右侧有调试台：

- 情绪和强度滑块，应用到特效页。
- 「单步点赞」只打一条模拟事件。
- 时间轴滑块拖 GSAP 时间线，用来对一下镜头和打印占位。「回到直播」取消拖动。
- 底下显示特效页上报的 FPS、帧时间、粒子数、在场特效数、是否降档。

虚拟打印仍是进度和场景里的一块占位，不是完整的打印工作台。

## 录一段验收画面

1. OBS 按上面加好浏览器源，预览里能看见透明特效。
2. 管理页把回放速度调到 20x，或点「大礼物榜一」。10 倍事件流也可以跑 `python scripts/benchmark_overlay.py --rate 20 --seconds 20`，那是无界面的近似，不是 OBS 本身。
3. 看管理页调试台：FPS 希望不低于 55，帧时间不高于 12ms。若掉下去，应出现「已降档」。
4. 用 OBS 的「开始录制」录 1 到 3 分钟。录完看任务管理器里 OBS 或浏览器源的内存没有一直往上爬。
5. 真实 OBS 上的 FPS 和内存记到 `docs/p3-benchmark.md`。云环境跑不了 OBS 和独立显卡时，那里会写「待实机验收」，并附上无头 Chrome 的近似结果。
